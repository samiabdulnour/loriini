How it works

A folder, no administrator rights, three steps.

  1. Download the folder. It holds Loriini.exe, the add-on LoriiniAddOn_AC26_Win.apx, an install note and the licence.
  2. Put both files in one folder of your own, for instance Documents\Loriini\Add-Ons. The menu item looks for the program beside the add-on.
  3. In Archicad: Options › Add-On Manager, add that folder, restart. A Loriini menu appears, and starts the program.

The licence

A subscription is counted in seats: a seat is a computer that has used Loriini in the last fortnight. One key per practice, pasted once on each computer. Loriini checks in with the licence service by itself and works for a fortnight without a connection. A computer that stops using Loriini frees its seat after a fortnight, or at once with Loriini.exe licence --remove.

Needs

Windows 10 or 11, Archicad 26. Loriini talks to Archicad on the same computer; nothing about a project leaves it.
