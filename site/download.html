Copy Loriini.exe and the one add-on whose number matches your Archicad; the others are for the other versions and will not load. The program asks for a licence key the first time it opens. Without one it still lists its rulesets and reads a model, and touches nothing. The same download serves a trial key and a subscription. How to install it is on How it works.

Prototype, not validated for submission. Loriini is for design-stage iteration. Its figures have not yet been validated against a reference implementation on a real project, and must not be used as a compliance figure in a DA submission. A DA submission rests on a consultant's report. This notice stays until the validation is done.
